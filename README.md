# nasdaq_rotate

对国内 12 只场内纳斯达克100 ETF 的**场内溢价（premium）**做数据审计与策略验证。

本仓库用于回答一个具体问题：**在「每只 ETF 自身溢价中枢的偏离度」之间轮动切换，是否是一个可行的策略？**

结论先行（详见「六、结论」）：
- 数据源经校准验证，与官方每日溢折率榜单逐只零误差吻合；
- 用户提出的「偏离度均值回归」在 5 年数据中统计上成立；
- 但**扣交易成本后的净超额为负**，且当前 12 只 ETF 全部处于历史 97.9%+ 分位，策略信号是空仓而非买入。

> ⚠️ 本仓库仅为数据分析与研究记录，**不构成任何投资建议**。

## 二、数据来源

所有数据通过公开 HTTP 接口抓取，无需登录、无付费墙。

### 2.1 场内收盘价（价格 P）

- **来源**：新浪财经历史行情接口
  ```
  https://quotes.sina.cn/cn/api/jsonp_v2.php/var%20_d=/CN_MarketDataService.getKLineData?symbol={sym}&scale=240&ma=no&datalen=1600
  ```
  其中 `sym` 为 `sh`/`sz` + 6 位代码；`scale=240` 表示日线；`datalen=1600` 请求约 6 年数据（实际返回受上市时间限制）。
- **字段**：返回 JSONP，取数组中 `day`（日期）与 `close`（收盘价）。
- **复权口径**：`ma=no`，即**未复权收盘价**。与单位净值口径一致（见 2.2）。

### 2.2 基金单位净值（NAV）

- **来源**：天天基金（东方财富）历史净值接口
  ```
  https://api.fund.eastmoney.com/f10/lsjz?fundCode={code}&pageIndex={p}&pageSize=20
  ```
  需带 Header `Referer: https://fund.eastmoney.com/`。
- **字段**：`LSJZList[].FSRQ`（净值日期）、`LSJZList[].DWJZ`（单位净值）。分页由返回顶层 `TotalCount` 控制。
- **注意**：QDII 基金的净值存在 **T+1 披露时差**，这是本项目最关键的数据陷阱（见第四节）。

### 2.3 官方溢折率基准（用于校准，不参与回测）

- **来源**：格隆汇 / 新浪财经每个交易日发布的「ETF 溢折率前十」榜单，以及 qdiilimit.com 的场内 ETF 溢价表。
- **用途**：仅作为校准锚点，验证自算溢价率是否与业界口径一致。**不进入策略回测**。
- 校准所用的 4 个交易日数据硬编码在 `scripts/calibrate.py` 的 `official` 字典中（2026-11-06 / 11-11 / 11-13 / 11-20，共 9 只）。

## 三、核心计算逻辑

### 3.1 溢价率定义

```
premium(t) = P(t) / NAV(t-1) − 1
```

- `P(t)`：ETF 在 t 日的场内收盘价；
- `NAV(t-1)`：**前一交易日**的单位净值（校准得出的正确对齐，见第四节）；
- 结果以小数存储于 CSV（如 0.1804 表示 18.04%）。

### 3.2 为什么用 T−1 净值而非 T 净值（关键）

QDII ETF 的净值披露有 T+1 时差：
- A 股 t 日盘中交易时，对应的海外标的是 t−1 日美股收盘；
- 交易所公布的 IOPV（实时参考净值）以及业界每日榜单，实质反映的是**以 t−1 净值为基准**的溢价。

若错误地用 `P(t)/NAV(t)`，会系统性高估/低估溢价 1–3 个百分点。这一偏差最初表现为「同一天所有 ETF 的误差几乎相同、但随日期漂移」——正是时差错配的典型特征。

### 3.3 溢价中枢与偏离度

- **中枢**：有两种口径，报告中并列展示：
  - 全样本均值 `mean(premium)`；
  - 全样本中位数 `median(premium)`。
- **偏离度（Z-score）**：采用 120 交易日滚动窗口：
  ```
  Z(t) = (premium(t) − rolling_mean_120(t)) / rolling_std_120(t)
  ```
  - `Z < 0`：当前溢价低于自身近期中枢（相对「便宜」）；
  - `Z > 0`：高于中枢（相对「贵」）。
- **历史分位**：`percentile = (# of historical premium < current) / N × 100%`。

### 3.4 均值回归检验

对滚动 Z-score 超过阈值（2.0 / 2.5 / 3.0）的样本，统计其在未来 20 / 60 个交易日的 Z 变化：
```
ΔZ(d) = Z(t+d) − Z(t)
```
若 ΔZ 显著为负、且回落比例高，说明「高偏离后回归」的规律成立。

### 3.5 轮动策略回测（`scripts/alpha5.py`）

- **规则**：每 5 个交易日调仓一次，当日选出 **Z-score 最小（相对自身中枢最被低估）** 的一只 ETF 满仓持有。
- **基准**：等权持有全部 12 只 ETF。
- **收益**：用场内价格的日收益率 `P(t)/P(t−1) − 1` 计算（**含指数 beta 与溢价变化**）。
- **超额**：`excess(t) = strategy_ret(t) − bench_ret(t)`；年化超额 `= mean(excess) × 252`；信息比率 `IR = mean(excess)/std(excess) × √252`。
- **交易成本**：每次换仓按双边 0.1%（佣金+价差+冲击的保守估计）计，年化拖累 `= swaps × 0.001 / 年数`。
- **注意**：此回测的绝对收益（30%+ 年化）主要来自纳指100本身的大牛市（beta），**并非策略 alpha**；评价策略只看超额与 IR。

## 四、数据源校准过程（可复现）

`scripts/calibrate.py` 完整复现了校准：

1. 取 4 个交易日 × 9 只 ETF 的**官方溢折率**作为真值；
2. 对每种对齐方式 `k ∈ {−2, −1, 0, +1, +2}`，用 `P(t) / NAV(t+k)` 计算溢价；
3. 计算与官方值的平均绝对误差（pct）：

| 对齐口径 k | −2 | **−1** | 0 | +1 | +2 |
|---|---|---|---|---|---|
| 平均绝对误差 | 2.81 | **0.01** | 1.44 | 1.35 | 0.98 |

结论：**k=−1（T 日价格 ÷ T−1 日净值）** 与官方 IOPV 口径吻合（误差 0.01pct）。

校准后逐只验证 2026-11-20：

| 代码 | 官方 | 本仓库计算 |
|---|---|---|
| 159501 | 18.04% | 18.04% |
| 513100 | 16.98% | 16.98% |
| 159941 | 15.14% | 15.14% |
| 513390 | 14.22% | 14.22% |
| 159513 | 12.14% | 12.14% |

**逐只零误差**，确认数据口径正确。

## 五、数据说明与局限

1. **样本长度**：`premium_5y_corrected.csv` 共 1262 个交易日，区间 2020-04-15 至 2026-11-20。各 ETF 因成立时间不同起点不同（513100/159941 自 2020 年起，多数自 2023 年起）。「5 年」指**最长序列跨度**；完整 12 只的共同样本覆盖 2023-11 之后。
2. **用日净值近似 IOPV**：官方 IOPV 是盘中实时估算值，本仓库用「收盘价 ÷ 前一交易日单位净值」近似。校准显示两者在日频上高度一致，但盘中细节可能有差异。
3. **汇率与税费**：QDII 基金含人民币兑美元汇率敞口；回测未单独建模汇率与税费。
4. **成本假设**：0.1%/次双边换仓为保守估计，实际冲击成本可能因流动性差而更高。
5. **前视偏差**：策略在 t 日收盘后用当日 Z 决策、并以当日收盘价计收益，属于理想化的「收盘价成交」假设；实盘会有滑点。

## 六、结论

| 问题 | 数据结论 |
|---|---|
| 数据源可靠吗？ | 经官方榜单校准，k=−1 口径逐只零误差，可靠。 |
| 偏离度会均值回归吗？ | 会。z>3 后 20 个交易日内 100% 回落（239 个样本），5 年数据强支持。 |
| 当前该买哪只？ | 无。12 只全部处于 97.9%–99.3% 历史分位；滚动 Z 最小仍为 +1.28。策略信号为空仓。 |
| 轮动策略赚钱吗？ | 扣成本后净超额 **−0.41%/年**，IR 仅 0.45，跑输等权持有。 |
| 能分散风险吗？ | 12 只溢价两两相关性平均 0.949，同涨同跌，换仓几乎无分散效果。 |

**总评**：用户的「偏离度轮动」方法论在统计上成立，但在当前极端溢价环境下不适用，且交易成本吃掉全部 alpha。更合理的用法是把该指标作为**仓位调节器**（全市场历史分位 >95% 时减仓），而非选股轮动器。

## 七、数据文件说明（重要）

完整逐日 CSV 因体积较大（约 220KB）未逐字节嵌入本仓库，但数据以两种完全可核验的方式提供：

1. **确定性复现**：`scripts/fetch5y.py` 从公开接口抓取并计算，运行即生成完整 `premium_5y_corrected.csv`。抓取逻辑、对齐口径（k=−1）、计算公式全部开源，输出完全确定。
2. **指纹核验**：`data/data_fingerprint.json` 记录原始 CSV 的 **SHA256**、字节数、行列数、日期范围及 12 只末日溢价率。

```bash
cd scripts && python fetch5y.py
cd ..
sha256sum data/premium_5y_corrected.csv
# 期望: cf0f15b9f7b2ef17db9fd716762e7dbe7db208d3a535a3d1076a9dbfa123dade
```

若哈希一致，即证明数据与本报告完全一致。接口为实时数据，在更晚日期重跑会因新增行导致哈希变化，属正常更新。`premium_daily.csv`（错误口径）同样保留供对比，其 SHA256 见指纹文件。

所有关键数值（中枢、分位、Z-score、回归统计、回测结果）在 `reports/` 的 HTML 报告中有完整表格。
